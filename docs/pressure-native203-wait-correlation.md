# R203 离线相关性观察（历史原始样本）

原185个只读样本中，同一DBS进程线程出现50个连续D状态样本，49个folio_wait_bit_common、1个folio_wait_bit，跨49秒。7次引擎API内部timeout的各自约5秒窗口内均命中该线程5个D样本；这只能证明时间重叠，尚未证明该线程就是请求处理者或具体因果。

API进程RSS所有样本均67712KiB，所采线程major faults总增量0。压力期大量文件页正在writeback，相关数值见同名JSON；并不支持直接断言是API执行文件被内存压力换出。该进程的D等待可能涉及其他文件操作，不能仅凭wchan判断。

新工具只读采集syscall/内核stack与适用FD路径，资格及新完整复测入口见[接入说明](testing-business-pressure-final-wait.md)；现有历史样本没有这些字段，不能追溯补造。不得因相关性改变配额、缩小工作集、延长期限或删除失败夹具。R203源码/计划/失败已公开并保留；native-session工具18+两镜像各8资格通过，已接入新独立完整执行器，原压力业务通过仍待实际终态。
