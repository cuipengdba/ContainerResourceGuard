# 事件发生时的内核端点诊断与本轮失败

本轮开发了独立、默认只读、需双重实验标记的诊断工具，未更换CRG产品源码、依赖或preview.4发布文件。独立进程21项资格通过；厂商隔离副本原计划22项，实际记录19项、通过18项，DBS严格端口关联检查失败，整体保持失败。原始失败、源码和观察收据见[结构化结果](test-results-event-time-kernel-endpoint.json)与[完整证据](test-evidence/event-time-kernel-endpoint.json.gz)。

## 独立进程与实现边界

[冻结工具](../tests/event-time-endpoint-host-frozen-v1/kernel.go)先按精确TGID和v2 cgroup ID过滤，再使用BTF验证的字段尺寸及指针类型关系，从当前任务的FD表读取仅限IPv4回环TCP的端口和inode整数。16字段从同一份有界BTF字节解析并记录摘要；文件类型、SOCK_STREAM、地址族、回环地址、连接状态、FD范围及同一FD槽引用都检查后才提交元数据。失败保持unknown；不输出指针、不读用户缓冲/请求/日志内容，不ptrace或复制目标FD，不写业务cgroup/tracefs/sysctl，不安装系统包或持久pin。

32个立即关闭的真实连接全部正确关联accept/recv/send/close，复用了同一个数值FD；客户端耗时50838–149016纳秒，采集器延后约500–511毫秒解码仍能关联，未加响应保持。AF_UNIX、UDP及两个无效FD未被标成TCP。原真实EAGAIN及500526765纳秒阻塞管道检查保留。正常18事件、快速284事件均完整排空且无观察到的丢失；真实满环测试204事件/BPF输出失败199800/perf丢失0，正确标为incomplete。两类丢失计数不相加，未采集输出失败errno。8个原进程实例和45个临时BPF对象独立确认消失，无强制清理。

FD槽复查不使遍历原子化，顺序FD复用成功不代表所有并发关闭/复用竞态已证明安全或关联正确。元数据可用性、全局根因和完整业务验收分别保留原判定；不能把“无观察到丢失”解读成完全无扰动。

## DBS中观测到的日志write长等待

同一原服务线程3262334对FD3原日志/opt/dbs/log/DBS.log写143字节，从单调时间1443011638413047至1443023787899592持续12149486545纳秒，返回143。该线程在此期间没有进入后续accept；返回后才接收排队连接。两个客户端失败请求的实际端口均由事件发生时的整数元数据取得：

| 36524 | 8.948967秒 | 8.949436秒 | 9.582958秒 | 4秒socket timeout |
| 36592 | 3.949106秒 | 3.950503秒 | 4.593706秒 | 4秒socket timeout |

第一请求的完整超时等待发生在该日志write仍未返回期间；第二请求接收接近超时，发送已晚于超时。日志write前该线程服务的是另一个实际回环端口60132，该端口不在本轮25个原生API客户端记录中，不能冒充为已识别的具体调用来源。这里只确认系统调用和排队处理时序，不宣称已经区分IO控制器等待、文件系统folio/回写、CPU调度或锁等待，也不据此将此前所有错误归为同一原因。产品修复、全局因果证明和稳定业务验收仍为false。

70个不同原进程实例、60个BPF对象、两个Pod/父叶cgroup和namespace独立确认移除，原配置字节及profile缺省恢复。DBS失败后的显式disable验收项未执行，不算通过；最终隔离副本清理证据单独保留。原memory.high七天任务和旧策略长期任务未重启，也未转移累计时间。

## 下一步与发布状态

当前5.14节点只读发现balance_dirty_pages、bdi_dirty_ratelimit、folio_wait_writeback、global_dirty_state、writeback_wait五个静态格式，收据已归档；本次探测未加载BPF或读取业务数据。下一步先在独立进程资格中验证仅整数的等待/回写元数据，再用于新隔离副本定位长write来源；先补齐失败前保存关联的测试记录逻辑，不以延长4秒期限、提高原IO限额或重复未改观测的完整600秒来取得通过。

当前可下载版本仍为v1.0.0-preview.4；memory.high允许超出目标并触发回收/节流，外部硬上限保留。原完整压力/API失败、默认20%场景、七天604800秒/28周期及老化后置、正式24小时、ARM64/Linux6真机、多独立物理设备及实际已发布次版本升级门槛均保持，全部52原任务定义不变，未发布1.0稳定版。
