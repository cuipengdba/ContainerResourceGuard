# ContainerResourceGuard v1.0.0

发布日期：2026-11-17。按用户“正式发布１．０版本啊”的明确要求，现在发布正式版本，不再标记为prerelease。本次是提前发布决策，**不代表所有长稳、老化后或实际回退验收已经通过**；原验收标准、失败和未完成记录保留，测试继续。

## 交付功能

- 每容器一份Agent，只控制自身CPU、内存、IO；容器/Pod重建后自动重新识别自身cgroup。
- cpu_percent、memory_percent、io_percent分别设置，省略各默认20%；支持手动绝对值模式。
- CPU使用cpu.max；内存使用memory.high回收/节流，保留外部memory.max，不能保证绝无OOM。
- IO百分比仅限制标定读写带宽，IOPS仅手动可选；自动选择最大合格本地可写文件系统做标定。
- 仅纯cgroup v2设置，v1/混合/未知或权限不足记录并跳过；辅助程序故障不阻断原业务启动。
- 日志一天一份，保留30天，超过1,000,000,000字节自动清理。
- Linux AMD64与ARM64、配置/接入/升级/恢复文档、SBOM、构建元数据和SHA256校验文件。

## 下载与安装

从[正式Release](https://github.com/cuipengdba/ContainerResourceGuard/releases/tag/v1.0.0)下载匹配架构的containerresourceguard-v1.0.0-linux-amd64.tar.gz或arm64.tar.gz，以及SHA256SUMS。归档内crg为程序，BUILD.json记录准确身份，SBOM.cdx.json记录组件；完整文档随包提供。

```sh
sha256sum -c SHA256SUMS --ignore-missing
tar -xzf containerresourceguard-v1.0.0-linux-amd64.tar.gz
./crg build-info
```

最小配置为{}，或分别指定：

```json
{"cpu_percent":30,"memory_percent":40,"io_percent":25}
```

按[容器接入](../integration.md)、[安装与恢复](../installation.md)保留现有配置、profile、journal和日志，先在单个容器验证。原start.sh异步启动可选helper，业务不等待标定。更新运行中的程序使用原子替换，不截断原二进制。只接受memory.high兼容回退目标，旧max-only开发版拒绝。此Release没有执行生产服务器更新。
