# ContainerResourceGuard v1.0.0-preview.1

可立即下载更新的工程预发布版。**这不是稳定1.0发布**，真实七天、完整对照长期和未测环境条件继续验收。

## 本版功能

- 每个容器一份独立Agent，仅默认管理CPU、内存、IO。三个独立百分比各自默认20%，不需要总百分比或其他必填资源参数。
- 设置与自动标定前先检测cgroup。v1跳过；混合/未知不写；纯v2通过自身身份、权限、外部边界及内存安全校验后设置。版本和实际动作写入日志。
- 容器/Pod换ID后自动重新发现自身cgroup；默认后台选择最大合格可写本地磁盘文件系统进行IO标定并复用稳定设备基准。IO百分比对应实测基准。
- 每天一个日志文件，保留30个日历日或总量超过1,000,000,000字节时清理最旧日志；文件日志失败降级stderr。
- 可选辅助启动脚本不阻断原DBS/HISDBS启动；无权限、只读、缺文件和Agent失败明确记录。已写入内核的限额不会因Agent退出而自动撤销。
- 纳入组合候选已有的配置重载、诊断/可选指标、原值与冲突保护、停用恢复、维护升级/回退、分区设备解析能力；历史手动配置兼容。其他资源不新增默认控制。

```json
{"cpu_percent":30,"memory_percent":40,"io_percent":25}
```

上面仅为配置语法示例，不是DBS/HISDBS性能推荐值。原默认20%四格业务组合测试均未通过；本程序业务通过的是原先固定的手动64MiB/s测试预算。

## 下载与接入

[本次GitHub下载](https://github.com/cuipengdba/ContainerResourceGuard/releases/tag/v1.0.0-preview.1)。下载匹配架构的`containerresourceguard-v1.0.0-linux-amd64.tar.gz`或arm64包，以及`SHA256SUMS`，先核对压缩包摘要。包内含BUILD.json、SBOM.cdx.json、配置示例、可选helper和完整文档。

```bash
sha256sum -c SHA256SUMS --ignore-missing
# 在新建的私有空目录内解包；选择实际架构文件
tar -xzf containerresourceguard-v1.0.0-linux-amd64.tar.gz
./crg version
./crg build-info
```

旧`v0.1.0-rc.3-preview.1`缺少新维护协议广告，不能假定binary-install可以自动跨过此保护。更新时只停止旧CRG辅助循环及Agent，保留原配置、IO profile、journal、状态和日志及私有备份；确认旧Agent全部退出后，在同目录以临时文件+原子替换安装受信任的新程序，再独立启动helper。无需重装K8s或Operator，也不要求重启DBS/HISDBS主进程。保持原state_dir；不删除journal来绕过校验。若曾用八资源开发配置，先用对应旧程序disable并确认额外限额恢复。

每个容器分别放置程序和配置；默认运行`/opt/crg/crg run --config /etc/crg/config.json`，沿用现有可选supervisor入口。首次接入或Pod重建持久化见[安装](../installation.md)及[接入](../integration.md)。启动后用`status --config /etc/crg/config.json --format human`核对实际值和原因，检查`/var/log/crg/crg-YYYY-MM-DD.log`中的cgroup判断与执行结果。需要停用用匹配版本disable并逐项核对恢复，不以杀Agent代替恢复。

本次只发布GitHub下载包，没有替换现有任何业务环境。
