## 记录内容和边界

仅替换原引擎的probe函数：外层测量`kubectl exec -> su -> Python -> POST /test`全流程；容器内Python以单调时钟记录该请求/读取/JSON验证区间，保存进入Python、请求前后和退出前的时间。业务响应只验证200和Result=000，不输出响应正文、凭据、环境全集或任意异常文本。

保存每次探测前后的本容器cpu.stat、CPU/IO/内存PSI、memory.current/events和io.stat，只读且单文件最多16KiB。外层减内层只称为“HTTP请求区间以外的耗时”，其中包括exec/运行时、su、解释器启动/导入、返回与新增JSON解析；没有进一步分段，不能直接指认Kubernetes、容器运行时或CRG。新增测量自身有开销，不将新结果伪称原探测的同一测量。新样本若复现超5秒则据实际内外时长缩小本次样本范围；不复现也不关闭历史根因。
