# 共享程序切换与恢复演练

这是P02/P08的隔离验收工具，产品仍是每个容器一个Agent。DBS/HISDBS测试夹具恰好共用一个只读挂载的程序目录，因此先用独立克隆演练两个容器都停用后再替换共享文件，不能把旧四格中“每格独立程序”的结果直接套用。

[冻结计划](test-plan-shared-program-stage.json)记录首次执行前的脚本摘要、预算和条件。`tests/vendor-enforce-stage.py`默认只读，`--execute`只适用于固定测试夹具；先核对完整基线、原Pod/进程/cgroup与挂载、原值、源码和预留，再创建锁、备份或执行各容器CLI。基线未实际通过86400秒和四周期时必须拒绝，不能以零错误中间快照切换。

隔离演练包含两个角色各完整observe600秒，随后旧参考入口停用、持久备份、先写两份配置再原子替换共享程序、同一helper启动单Agent、候选保持120秒，最后各完整enforce600秒及备份/同步/独立恢复周期。CPU7.2核、内存20001980416B、读写各64MiB/s和4096IOPS为先前冻结手动预算；原SQL/API零错误、5秒最大、1秒p95、98%覆盖和64MiB数据保持不变。

`--recover`是单独的恢复入口，只读取本次私有记录和不可变旧程序/配置/状态备份；原负载必须终止且清理完成。它用旧程序恢复实际原值，然后恢复旧配置/程序，由同一helper启动旧observe Agent，不导入或删除journal、不修改业务或缓存进程。执行中的负载不能提前恢复或放宽预算。

本地10项验收门检查通过，包括损坏/缺失回执、短时冒充24h、单角色失败、缺周期/覆盖、越界周期及前置失败时禁止任何锁/输出/CLI操作。真实Linux拒绝和共享克隆演练尚未执行。成功后也只补这套切换/恢复过程的600秒证据；正式24h enforce、至少7天和硬件门槛仍独立保留。
