# 一次性厂商业务长期验收执行器

这些程序只用于授权的隔离测试节点，不是产品Agent，也不是部署或安装入口。执行器可协调两套测试Pod；实际产品始终每个容器各一份Agent，互不管理。

准确产品ELF、节点私有厂商夹具及原厂镜像均不随本目录公开。请先阅读[冻结计划与准入状态](../../docs/testing-final-v1-long.md)，禁止在业务命名空间运行。节点路径、namespace和run ID是本次唯一标识，不是用户配置项。不要直接重试已创建输出目录的任务。

当前只完成只读预检查，尚未创建本轮业务夹具、尚未启动长期计时。本目录文件除本说明外，与节点已上传的非二进制输入字节一致；plan.json列出全部输入摘要。未来结果须另存终态文件，不能编辑本冻结计划或把旧版运行时间计入新候选。
